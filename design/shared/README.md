# Shared design foundation
[Tokens](tokens.css) are the semantic prototype values for all three modules; [DESIGN.md](../../DESIGN.md) explains them. Production integration is a later task.
Patterns: labeled native controls, action hierarchy, feedback/status, persistent demo disclosure, current-context summary, empty/retry states and keyboard-visible focus.
No Figma library exists as a result of this scaffold. When created through the existing official plugin, record the file/node URL here and map these token names.
